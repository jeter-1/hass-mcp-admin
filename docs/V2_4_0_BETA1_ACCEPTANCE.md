## Later installed acceptance

Deployment and live access require separate owner authorization. Bind the running
image to its publication receipt; verify exact Engineering/Core/provider identity,
signed authority, native/delegated reads, fresh public catalog and approval-panel
access under the normal release contract. Use one existing script with a known
entity reference for a bounded dependency query; verify canonical script identity,
configuration path, provider/version, incomplete-inventory disclosure and cache
behavior. Do not execute a script or cycle a device for this diagnostic feature.
Finish with no-probe settlement, distinguishing historical counters from new errors.

No persistence migration is intended. Source recovery is a reviewed revert;
deployment recovery must preserve current execution records and reconcile any
uncertain operations under the existing compatible-reader procedure. Do not
restore stale execution state to satisfy acceptance.
