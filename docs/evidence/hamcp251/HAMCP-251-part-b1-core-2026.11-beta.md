### 0.2 Engineering reader reachability at the pinned base

**Fact — changed-needs-action:** there is a source-established, conditional Engineering path that can return an unredacted startup URL line: `get_incident_logs` → validated `addon:<slug>` source → matching host journal container → credential screen → shared sanitizer → returned message. The slug validator has no ha-mcp exclusion. The credential screen does not recognize every opaque path, and the known-secret set does not include the app's MCP path. A line containing the URL without a recognized credential label/pattern can survive. This finding was reported immediately during the trace; continuation is expressly authorized. It is not an observation that production has returned such a line.
