sensor/script/device, start options flows, create plans/approvals or restart.

1. Discover current schemas. Capture no-probe `server_info` and health; use one

   supported tools. Record counters and concurrent work.
2. Complete one native entity and one admitted delegated useful read; preserve
   provider attribution, completeness and fallback facts. Read one retained
