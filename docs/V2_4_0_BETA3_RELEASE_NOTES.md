publication, deployment or installed-acceptance result is claimed here.

leaves. Keep current array-suffix accounting, 16-operation and existing byte,

typed condition instead of matching a hard-coded 16-leaf message.

admission, signed Core authority, input schemas, persisted formats, approval
meaning, deployment options/permissions, dependencies and stable-v1 are unchanged.

remain disclosed. Older-binary handling of larger new plans is not established.
