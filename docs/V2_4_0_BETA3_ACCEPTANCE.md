## Recovery limits

Source recovery is a reviewed revert. Runtime dashboard recovery requires exact
pre-state and a separately authorized restoration, not automatic rollback.
The provider read/save interval remains non-atomic against external writers.
No stored format changes, but larger new plans have not been proven compatible
with an older binary: do not claim a binary-only downgrade is sufficient or
restore stale execution state to satisfy acceptance. Establish compatible
recovery for the actual installed state before deployment.
